# ── Ollama — Local LLM Client ─────────────────────────────────────────────────
# Ollama runs LLMs locally. This project uses it for:
#   - Embeddings:  nomic-embed-text (768-dim) — used in retriever + rag_retrieval
#   - Generation:  llama3.1:8b / mistral:7b / phi3:mini — used in generator
#   - Parser:      any chat model — section extraction, criteria parsing
#   - Compliance:  any chat model — fabrication detection, gap analysis
#
# Install Ollama:  https://ollama.com/download
# Pull models:
#   ollama pull llama3.1:8b        # primary LLM (generation)
#   ollama pull nomic-embed-text   # embeddings (retrieval)
#   ollama pull phi3:mini          # lightweight fallback LLM
#   ollama pull mistral:7b         # alternative generation model
#   ollama pull medllama2:7b       # healthcare-fine-tuned (optional, best quality)
